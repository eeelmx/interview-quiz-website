# 面试/答题网站 说明文档

一个纯前端、免后端的在线答题网站：注册登录 → 逐题作答 → 提交判分 → 结果回看 → 成绩与错题留存。
全部数据保存在浏览器 localStorage，不发起任何网络请求。

---

## 1. 运行步骤

1. 安装并打开 Chrome / Edge 等现代浏览器（本项目在 Edge 与 Chrome 内核下验证通过）。
2. 双击项目文件夹中的 `login.html`，即可直接在浏览器中运行（无需安装 Node、无需启动服务器）。
   - 也可用 VS Code 的 Live Server 插件启动：右键 `login.html` → Open with Live Server。
3. 按以下流程体验：注册一个账号 → 登录 → 选择试卷 → 逐题作答 → 提交答卷 → 查看成绩与逐题对错。
4. 刷新页面或关闭浏览器后重新打开，账号、已选答案、历史成绩仍然存在。

> 工程目录已按提交规范命名为：`刘铭萱-26软件工程2班-摸底任务`。

## 2. 技术栈

| 项目 | 说明 |
| --- | --- |
| 语言 | 原生 HTML5 + CSS3 + JavaScript（ES5 语法，保证兼容性） |
| 框架/库 | **无**。未使用 React、Vue 等框架，未引入任何第三方库或 CDN 资源 |
| 后端 | **无**。不需要服务器与数据库 |
| 数据存储 | 浏览器 `localStorage` 持久化，刷新、重开浏览器后数据不丢失 |
| 适配 | 响应式布局，电脑端卡片居中，手机端自适应（媒体查询断点 480px） |
| 浏览器 | Chrome / Edge 等现代浏览器 |

### 文件清单（7 个交付文件 + 本说明文档）

| 文件名 | 类型 | 职责 |
| --- | --- | --- |
| `login.html` | 页面 | 登录页：用户名 + 密码登录，含跳转注册页链接 |
| `register.html` | 页面 | 注册页：用户名 + 密码 + 确认密码，含跳转登录页链接 |
| `quiz.html` | 页面 | 答题页：欢迎语、试卷选择、题目区、上下题/提交、结果区、成绩与错题入口、退出登录 |
| `style.css` | 样式 | 三个页面统一样式，含移动端适配 |
| `app.js` | 逻辑 | 注册、登录、当前用户读写、退出、成绩记录读写及按钮绑定 |
| `questions.js` | 数据 | 题库数组（两套试卷，每套 8 道中文面试题） |
| `quiz.js` | 逻辑 | 未登录拦截、渲染、切换、答案保留、倒计时、判分、结果回看、成绩记录、错题本、退出 |

### localStorage 键说明

| 键名 | 内容 |
| --- | --- |
| `users` | 账号表，形如 `{ "小明": "123456" }` |
| `currentUser` | 当前登录用户名；退出登录后删除 |
| `answers` | 当前试卷已选答案下标数组（`-1` 表示未作答） |
| `answers_<试卷id>` | 按试卷分别保存的答案，保证切换试卷不互相覆盖 |
| `records` | 历史成绩数组，每项含 `user`、`score`、`total`、`percent`、`paper`、`time` |
| `wrongQuestions` | 本次作答答错的题下标数组 |
| `wrongSnapshot` | 错题作答快照（记录「你的答案」），用于错题本回显 |
| `paperId` / `timerOn` | 当前试卷 id / 是否开启每题限时 |

## 3. 已完成功能

### 必做功能（全部实现）

- [x] **用户注册**：用户名、密码、确认密码三项校验；重名提示「该用户名已存在，请换一个」；两次密码不一致提示。
- [x] **用户登录**：用户名不存在提示「用户名不存在，请先注册」，密码错误提示「密码错误，请重试」。
- [x] **未登录拦截**：未登录直接访问 `quiz.html` 会被立即跳回 `login.html`。
- [x] **题库**：两套试卷，每套 8 道中文面试题（合计 16 题，远超 5 题要求）。
- [x] **逐题作答**：每题渲染题干与 4 个单选选项，显示「第 X / N 题」与进度条。
- [x] **上下题切换**：可自由来回切换；第一题不显示「上一题」，最后一题显示「提交答卷」。
- [x] **答案保留**：选择即刻写入 localStorage，切题回来原选择仍在；刷新、重开浏览器后进度与答案不丢，并自动定位到第一道未答题。
- [x] **判分与结果**：提交后显示总分、正确率，并逐题显示「对/错 + 你的答案 + 正确答案」，结果在页面上可回看（刷新后仍可回看）。

### 扩展功能（四项全部实现）

- [x] **成绩记录**：每次提交写入 `records`，「历史成绩」面板按时间倒序列出答对数、正确率、试卷与时间（仅显示当前登录用户自己的记录）。
- [x] **错题本**：「错题本」面板列出本次答错的题目、你的答案与正确答案。
- [x] **倒计时**：每题限时 30 秒，最后 10 秒标红；超时自动进入下一题，最后一题超时自动提交。工具条上的复选框可随时开关。
- [x] **多套试卷**：A 卷「面试综合素养」、B 卷「职场沟通与团队协作」，答题页顶部下拉框可随时切换，两套试卷的作答进度互不干扰。

### 其他细节

- 退出登录：清除 `currentUser` 后跳回登录页，再访问答题页会被拦截；账号与历史成绩保留。
- 退出登录、切换试卷、再答一次等操作均有二次确认或明确提示。
- 提交时若仍有未作答题，会提示剩余题数（未作答按错误计分）。
- 提交后可点「再答一次」清空本卷答案重新作答。

## 4. 已知问题

- 账号、答案与成绩仅保存在**本机当前浏览器**的 localStorage 中；更换设备、更换浏览器或清除浏览器数据后会丢失，也无法跨设备同步（无后端，属于设计上的已知限制）。
- 密码以明文形式保存在 localStorage 中，仅适用于教学演示场景，不具备真实系统的安全性。
- 直接以 `file://` 方式打开时，若浏览器设置了「禁止本地文件使用本地存储」的隐私策略，数据将无法保存，此时请改用 Live Server 等本地服务器方式运行。
- 题目内容与判分规则为静态配置，需修改 `questions.js` 才能变更题库，页面内暂无后台管理功能。
- 错题本记录的是**最近一次提交**的错题，重复作答会覆盖上一轮的错题记录。
